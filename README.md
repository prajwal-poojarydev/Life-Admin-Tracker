# Life Admin Tracker

A simple and responsive web application to manage important documents, warranties, subscriptions, and renewals in one place.

## Features

- **Dashboard Overview:** View total items, active items, expiring items, and expired items.
- **Add Items:** Add documents, warranties, subscriptions, and renewals with dates and notes.
- **Upcoming Renewals:** Quickly identify items that are expiring soon.
- **Recent Items:** View recently added items with their current status.
- **Search and Filter:** Search items and filter them by category.
- **Item Details:** View item information, dates, status, and notes.
- **Delete Items:** Remove items that are no longer needed.
- **Dark Mode:** Switch between light and dark themes.
- **Local Storage:** Keep saved items in the same browser across page refreshes.
- **Responsive Design:** Use the application on desktop, tablet, and mobile screens.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## Getting Started

You can run this project locally without installing additional software.

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start adding and managing your items.

## Data Storage

The application uses browser Local Storage to save items. Data remains available in the same browser on the same website until it is cleared or removed.

Items are stored locally and are not automatically shared between different users or devices.

## Purpose

This project was built to practise front-end web development and create a practical tool for organizing everyday administrative tasks.
